# NAS - Automatisation :

## Description of the project :

This repository is created to stock and compile all the processus developped to automatise actions on my personnal NAS.

### You can find :
- Download_videos : A project which summarize and download videos selected from youtubers followed.
- Liste_course : A recipe workbook and shopping-list project.
- Menu_App : A desktop launcher with illustrated cards for the available tools.

Run `Menu_App/Menu_app.py` with Python to open the launcher. The video card starts
the downloader, and the recipes card opens `Liste_course/Recipe.xlsx`.
